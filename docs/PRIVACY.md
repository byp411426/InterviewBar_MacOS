# 数据与隐私

应用首次启动不含任何个人投递记录、邮件、私有表格地址或 API 密钥。

- 日程、投递表、待通知安排、导入历史、确认保存的邮件原文与备份位于 `~/Library/Application Support/InterviewBar/`。这些是你的个人文件，不应上传仓库。
- 菜单栏位置、面板尺寸、模型地址/名称、AI 开关和你填写的飞书链接保存在本机应用偏好设置中。
- API 密钥保存在 macOS 钥匙串。源码、扩展与导出 CSV 不含密钥。
- AI 识别会把你主动粘贴或选中的文本发送给配置的 HTTPS 服务商。不是全部处理都离线；不希望发送时关闭默认 AI，使用规则或手动录入。
- 服务商的保存、收费与隐私规则由服务商决定。应用不自动切换服务商，不跟随模型请求重定向。
- 飞书页面使用自己的网络请求与本机 WebKit 登录存储。应用不从浏览器提取邮箱密码。
- 扩展只在操作时采集选区，清除来源 URL 的查询参数与片段再交给本机，但 URL 路径与邮件正文仍可能包含个人信息。
- 无持续剪贴板监听、无遥测、无上传整库、无自动读取所有邮箱。
- 识别成功的临时缓存仅在内存保留最多 10 分钟 / 20 条；确认保存的原文会保留在数据目录，不会随缓存自动删除。
- 删除应用不会删除你的个人文件或钥匙串。完整清理时先导出备份，再删除自己的数据目录，并在“钥匙串访问”中删除此应用对应的模型凭据；不要误删其他应用的凭据。

发布包只包含程序、扩展、文档和校验文件，不包含作者本机数据。测试均使用虚构公司与示例链接。扩展 manifest 的 `key` 是用来稳定扩展 ID 的公钥，不是私钥或 API 访问凭据。

启用开发者签名的原生组件版本时，会把组件所需的有限快照写入本机 App Group，详见 [原生组件说明](NATIVE-WIDGETS.md)。普通发行版的桌面面板直接读取主应用内存数据。

## AI 配置与用量记录

- API 密钥按完整请求地址隔离存入钥匙串；不同路径不会自动共用密钥。旧版本按域名保存的密钥，只允许当前已保存的地址读取，以兼容升级。
- 服务商预设、API 地址和模型名保存在本机偏好设置，切换服务商可恢复此前保存的配置，不包含密钥。
- 连接测试会向当前表单指定的服务发送一段虚构通知，需要网络，也可能计费；不会发送剪贴板或日程库。
- `model-usage.json` 只保存最近 10,000 次操作的时间、服务域名、模型、用途、状态、耗时、HTTP 状态与服务商返回的 Token 数；不保存正文、API 密钥、完整 URL、请求 / 响应体或服务商原始报错。此文件仍属于你的本机使用记录，不应公开上传。
- 记录文件用本机文件锁和原子替换保存。文件损坏时保留原文件并提示；统计写入失败不会阻止你获得识别结果。
