# v0.10.2 · 修复输入框复制粘贴快捷键

修复“编辑安排”中链接已选中、按 ⌘C 或 ⌘V 却不生效的问题。应用现在提供标准「编辑」菜单，将快捷键交给当前输入框处理。

- ⌘A 全选、⌘C 复制、⌘V 粘贴、⌘X 剪切。
- ⌘Z 撤销、⇧⌘Z 重做。
- 同样适用于邮件正文、公司、备注等原生输入控件；保留密码框自身的保护行为。
- README 补充快捷键用法，安装包包含配置 AI、粘贴邮件、查看统计的演示截图。

验证：原生链接输入框和多行文本编辑测试通过；安装后的真实编辑窗口完成全选、复制、粘贴、剪切、撤销与重做操作验证。测试编辑已取消，已有日程文件保持不变。

适用 macOS 13+、Apple Silicon。退出后替换应用，再打开即可。若临时签名更新后钥匙串拒绝访问，请在 AI 设置重新保存自己的密钥。仅限非商业使用，详见 LICENSE。
