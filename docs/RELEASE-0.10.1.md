# v0.10.1 · 修复桌面组件变形与圆角裁切

两个桌面玻璃组件现在固定为 11:7，只能等比例缩放，不能独立改变宽高。文字、间距和圆角随整个组件同比例变化。

- 在原生窗口设置固定内容比例；拖边缘或角时由 macOS 约束尺寸。
- 固定设计画布，避免内容撑出窗口、圆角被裁掉。
- 同时裁切原生玻璃背景和内容层，细化边缘与留白。
- 旧版被拉变形的尺寸在打开时自动修正，保留左上位置；超出屏幕的部分移回可见范围。
- 保存缩放后的大小，主菜单栏面板原有的独立宽高调整不变。

验证：旧尺寸修复、比例、位置、屏幕边界与重复恢复测试通过；两个原生圆角容器在 4 个比例下的布局和裁切测试通过；桌面运行确认圆角与玻璃外观正常。

实现依据：[Apple NSWindow.contentAspectRatio](https://developer.apple.com/documentation/appkit/nswindow/contentaspectratio)。应用自身的桌面面板更新，系统 WidgetKit 扩展的签名要求不变。

适用 macOS 13+、Apple Silicon。退出应用后替换程序再打开，个人日程与 AI 配置继续保留。仅限非商业使用，严禁商业盈利，详见 LICENSE。
