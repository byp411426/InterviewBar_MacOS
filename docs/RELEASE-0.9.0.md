# v0.9.0 · 图表统计与桌面玻璃组件

- 秋招之旅改为统计看板：每周分类柱状图、累计趋势、记录明细；支持统计口径、时间和类型筛选，点击某周查看记录。
- 两个独立桌面组件：最近安排倒计时、本周分类统计。玻璃材质，可移动、调整大小、设置置顶并记住显示状态。
- 原生 WidgetKit 的两种组件源码与签名构建脚本已提供。源码编译通过，但当前没有开发者签名身份，系统组件库安装和共享容器运行未验收。**此 ZIP 不包含可从系统组件库添加的原生组件。**
- 保留 120 条本机随机鼓励语、邮件识别、手动录入、数据导出与非商业许可。

统计只将手动标记“已完成”的安排计为完成；“全部安排”不是参加次数。近几周截至本周日，全部时间包含未来安排。按北京时间、安排日期归周。

安装包适用于 macOS 13+ / Apple Silicon，临时签名，未经 Apple 公证。系统原生扩展目标为 macOS 14+，需开发者自行完成签名与安装验收。重要提醒仍受系统权限、休眠和专注模式影响。
