# v0.10.3 · 待确认记录也能完成、取消和修正

待确认 / 时间待通知记录现在拥有与普通安排一致的操作菜单：**编辑安排、标记已完成、恢复待办、取消安排、标记未通过**，也保留带确认提示的删除入口。

- 不强制补时间即可标记完成；待办、已完成、全部筛选及顶部数量同步更新。
- 识别有误时可修改公司、类型、日期、时间和链接；补齐确切信息后转为同一条普通日程。
- 日程明细和 CSV 导出显示实际状态。
- 秋招之旅单独保留信息待补记录，不编造日期参与按周统计。
- 已完成或取消的待通知记录不会被新邮件静默重置为待办。
- 原有无状态字段的数据兼容读取；状态和编辑持久保存，写入失败保留原记录。

验证：状态切换、未知时间完成、错误日期校验、稳定 ID 转换、历史保护、重启加载、删除及失败保护测试通过。本机检查操作菜单、修正窗口和取消保存；个人记录保持不变。

适用 macOS 13+、Apple Silicon。退出后替换应用再打开；个人数据保留。若系统钥匙串在更新后拒绝访问，可在 AI 设置重新保存自己的密钥。仅限非商业使用，详见 LICENSE。
