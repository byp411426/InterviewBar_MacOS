# v0.8.0

新增“我的秋招之旅”：周时间轴、四种类型的完成次数、状态修改和 120 条随机鼓励语。菜单栏增加旅程入口，保留面板拉伸和原有安排。

首次安装从空白记录开始。飞书地址改为由使用者填写，API 密钥由使用者在设置中配置并保存在钥匙串。源码及安装包不包含作者的个人日程、邮件、私人表格或密钥。

README 包含安装、API 配置、复制邮件、粘贴识别、核对保存、统计口径、扩展安装、备份和常见问题的逐步说明。

验证：9 组 Swift 测试通过；本机 ARM 构建与签名校验通过；安装后的旅程入口、筛选和鼓励语切换已检查；Chrome 本机桥接 ping 与重复安装脚本通过。扩展的 Chrome 页面交互未作本轮端到端验收，复制粘贴入口可独立使用。

下载 ZIP 后，可在终端运行 `shasum -a 256 下载的ZIP路径`，与 SHA256SUMS.txt 中的值比对。校验值用于检查下载完整性。
