# v0.10.0 · 多模型配置与用量统计

邮件识别窗口新增「AI 设置与用量」。首次使用会引导配置，选择 DeepSeek、千问、Kimi、GLM 即可填入预设，也可填写自己的兼容 API 地址、模型与密钥。

- 密钥保存在本机钥匙串，按完整 API 地址隔离，兼容原有 DeepSeek 配置。
- 连接测试使用虚构通知，验证字段提取；测试不会保存配置，需要再点「保存并使用」。
- 用量页按时间、用途和服务域名筛选，显示输入 / 输出 Token、服务端缓存输入与命中率、本机复用次数、耗时与调用状态。
- 失败请求保留服务商已返回的用量；未知字段显示「未提供」，不算作零，不虚构费用。
- 本机用量记录不含正文或密钥，只统计本应用，自此版本开始保留最近 10,000 条操作。
- README 补全配置、复制邮件、粘贴识别、核对保存以及统计口径说明。

验证：10 组测试通过；四家请求参数与 usage 响应模拟通过；DeepSeek 真实连接、字段提取、服务端缓存、本机复用和 macOS 配置 / 用量界面验证通过。千问、Kimi、GLM 尚未使用对应账号做真实调用验证。

限制：仅支持 OpenAI Chat Completions 兼容接口；不估算费用或读取其他软件用量。普通发行版仍使用应用自带桌面玻璃面板；系统 WidgetKit 组件需另行配置开发者签名，详见原生组件文档。

适用 macOS 13+、Apple Silicon。没有 Developer ID 公证。更新时退出应用、替换程序再打开，个人日程继续保留；若钥匙串拒绝访问，请在配置页重新保存自己的密钥。
