# Chrome 扩展（可选）

日常使用无需扩展：复制邮件正文，点击菜单栏的“粘贴识别邮件”即可。

1. 安装并打开“面试日程.app”。建议放在当前用户的“应用程序”中。
2. 打开终端，输入 `zsh `（末尾留空格），把 `scripts/install-browser-host.sh` 拖进终端，再按回车。默认应用路径是 `~/Applications/面试日程.app`。如果放在其他位置，在脚本后加空格，再把应用拖进去。
3. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角“开发者模式”。
4. 点“加载已解压的扩展程序”，选择本包的整个 `BrowserExtension` 文件夹（不是单独的文件）。保留这个文件夹，之后不要移动或删除。
5. 点击 Chrome 工具栏的拼图图标，把“面试日程 · 邮件采集”固定。浏览器扩展不会由应用自动安装。
6. 打开一封招聘邮件，选中正文，右键 → “加入面试日程（识别选中文字）”；或者点扩展图标，确认选中文字后点“识别并送到应用”。
7. 如果邮件 iframe 不允许读取，直接在扩展文本框按 ⌘V；也可以使用应用自身的粘贴入口。
8. 在应用中核对字段，再确认保存。扩展不会直接修改投递表。

显示“应用尚未连接”：确认应用位置与第 2 步一致，重跑注册脚本，然后重新打开扩展。
更新扩展：替换原文件夹内容，在 `chrome://extensions` 点击扩展的刷新按钮。
卸载扩展：Chrome 扩展页点“移除”，再删除 `~/Library/Application Support/Google/Chrome/NativeMessagingHosts/app.interviewbar.macos.json`。

权限用途：activeTab / scripting 只在点击扩展时读取当前页选中文字；contextMenus 提供右键入口；nativeMessaging 连接本机应用；storage 临时保存错误提示。无全站后台抓取、无邮箱密码读取、无持续剪贴板监听。manifest 中的 key 是固定扩展 ID 用的公开公钥，不是 API 密钥。
